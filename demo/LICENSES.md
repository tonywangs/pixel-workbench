# Photograph provenance

All six files are unmodified samples from scikit-image **v0.25.2**. The upstream [data source documentation](https://raw.githubusercontent.com/scikit-image/scikit-image/v0.25.2/skimage/data/_fetchers.py) records these licenses and credits:

| File | Credit | Upstream license statement |
|---|---|---|
| astronaut.png | NASA; portrait of Eileen Collins | Public domain |
| camera.png | Lav Varshney | CC0 |
| chelsea.png | Stefan van der Walt | CC0 |
| coffee.png | Rachel Michetti; Pikolo Espresso Bar | CC0 |
| hubble_deep_field.jpg | NASA; Hubble eXtreme Deep Field | Public domain |
| clock_motion.png | Stefan van der Walt | Public domain |

The precise retrieval URLs, revision, byte hashes, and dimensions are in `sources.json`. `scripts/acquire.py` is the reproducible acquisition command and verifies hashes on repeat acquisition. These are real photographs, not generated fixtures. Portrait and landscape refer to output compositions; the portrait subject is Eileen Collins. No endorsement by photographers or subjects is implied. The PNG exports and screenshot are derived from these files.

Rendering scope & workspace recovery

Static paths, shapes, local gradients and clipping only. Text, stylesheets, embedded images, external resources, scripts and animation are rejected. Convert text to paths first. Default currentColor is black. Viewports are clipped; widths are 1–4096 px, maximum 8 megapixels per output. Maximum 24 files, 48 variants, 256 KiB per SVG.

Settings are saved locally in this browser, not source bytes. After reload or opening a project, reattach the exact same SVG files to restore their selections. SHA-256 must match. A project file is portable settings; an export ZIP also preserves your originals. This app needs the local Node server and a modern browser.

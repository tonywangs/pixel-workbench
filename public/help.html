A folder in.
A clear record out.

Import a folder, or try the bundled 24-image public-domain Met collection. The folder picker includes nested folders and all files the browser discovers. Import replaces the current collection; save a project first to keep your work.

Select and arrange

Click a thumbnail for a larger inspection. Check the images to include. Selected images appear in print order; use arrows or the position field to rearrange them. Select all preserves your existing order and appends excluded images. Filename order sorts selected images by their full relative paths, using case-sensitive code-unit ordering.

Recover and move

Selection, order, settings and source bytes are saved in IndexedDB after changes. Reload to recover. Use Save project to download a portable JSON backup; Open project validates hashes and reconstructs thumbnails. Browser storage can be cleared or evicted: the JSON backup is the durable copy. Stay on the same local host and port to access the same saved workspace.

Print and identify

Choose A4 or Letter, a grid from 2–4 columns and 3–5 rows, and filename or relative-path labels. Export creates two explicit download links: a PDF and its JSON manifest. Download both. Print at actual size / 100%. Sheets use 30-point side margins. No physical printer validation is claimed.

Images are fitted without cropping. Labels are 8pt, wrap to three lines, and abbreviate long names with “…”. A unique S-number and 10-character hash appear below each filename; the manifest keeps the complete original name, full hash and page/cell. Non-ASCII characters and control characters are printed as [U+XXXX] escapes to avoid missing font glyphs or invisible characters. The browser and manifest retain the original text.

Supported inputs

JPEG, PNG, still WebP, still GIF and single-page TIFF are decoded by content, not extension. Animated and multipage images, SVG, RAW, HEIC and other formats are rejected with reasons. Corrupt images and images above 40 million pixels are rejected. EXIF orientations 1–8 are applied before thumbnails and PDF placement. Transparency is flattened on white. Embedded profiles are converted to sRGB by Sharp/libvips; unprofiled images are interpreted by the decoder. This is not a color-proofing tool.

Limits: 100 discovered files, 10 MiB each, 50 MiB total source bytes. Whole collections over the count or aggregate-byte limit are refused without replacing the workspace; reduce the input folder and retry. An individual oversized file within those limits is listed as rejected. Accepted images are downsampled to fit within 1600 × 1600 pixels for previews and PDFs, encoded as JPEG at quality 90 (4:4:4); source bytes in project backups remain unchanged. Small originals may print softly. The browser can only account for files exposed by its picker, not inaccessible or hidden files it omits.

Local by design

The server binds to 127.0.0.1. Images travel only between your browser and that local process; the running app makes no external network requests. It reads no arbitrary folders and never writes to your originals. The demo is bundled with source metadata under demo/provenance.json. No telemetry, account or cloud storage is involved.

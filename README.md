# Personal Image Tools

Independent utilities collected into one private repository. Each lives under `tools/<name>/`; run its installation and commands from that directory. This is a source consolidation, not a unified application.

Original repositories and server workspaces were retained. Original histories are reachable through merge commits and `history/` tags. Unpublished source was copied from the server; it may be incomplete.

- [photo-metadata-desk](tools/photo-metadata-desk/README.md): A local photo-metadata workbench for inspecting embedded information and exporting cleaned JPEG copies with verifiable removal and preserved appearance.
- [photo-duplicate-review](tools/photo-duplicate-review/README.md): A local photo comparison workbench that distinguishes identical files from visually similar candidates and saves inspectable keep-or-review decisions without modifying originals.
- [contact-sheet-desk](tools/contact-sheet-desk/README.md): A local image-selection workbench that produces printable contact sheets with readable filenames, stable ordering, and an inspectable source manifest.
- [responsive-image-desk](tools/responsive-image-desk/README.md): A local workbench for preparing responsive image packages, comparing compression results, and exporting verified images with usable HTML.
- [image-crop-desk](tools/image-crop-desk/README.md): A local image-cropping workbench for preparing multiple compositions, recovering editable selections, and exporting crops with verifiable source coordinates.
- [svg-export-desk](tools/svg-export-desk/README.md): A local SVG export workbench for inspecting vector artwork and producing dimensioned PNG packages with explicit rendering limits.
- [animation-frame-desk](tools/animation-frame-desk/README.md): A local animation workbench for ordering image frames, editing timing, previewing playback, and exporting verified animated WebP files.
- [sprite-atlas-desk](tools/sprite-atlas-desk/README.md): A local sprite-atlas workbench for packing image assets, inspecting placement, and exporting independently verified PNG atlases with reusable coordinates.

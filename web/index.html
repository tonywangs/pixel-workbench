02 / Export selected copies

Removes EXIF personal fields, GPS, thumbnails, XMP, IPTC, and comments. Retains minimal orientation/color fields, ICC profiles and JPEG image data.

Choose photos to begin.

Less metadata is not anonymity. Faces, landmarks, text, filenames, filesystem timestamps, and retained ICC profiles can identify people or devices. Unknown containers and unsupported variants are refused. A separate audit contains original names and metadata: keep it private. Cleaned downloads contain only numbered JPEGs in a TAR archive.
